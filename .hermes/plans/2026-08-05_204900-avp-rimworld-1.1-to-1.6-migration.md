# AVP-RimWorld 1.1 → 1.6 Migration Plan

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** Migrate the Alien Vs Predator RimWorld mod from RimWorld 1.1 to RimWorld 1.6 (latest, including Odyssey DLC compatibility).

**Architecture:** The mod consists of 6 C# projects (RRYautja main, HunterMarkingSystem, PawnShields, ResourceBoxes, TrapsRearmable, ClassLibrary1), 164 XML def files, 14 patch files, and 392 C# source files. The migration updates NuGet references, C# code for API changes, and XML defs for schema changes across 5 RimWorld versions (1.1→1.2→1.3→1.4→1.5→1.6).

**Tech Stack:** C# / .NET Framework 4.7.2, MSBuild, Harmony 2.x, Krafs.Rimworld.Ref NuGet, RimWorld 1.6, Humanoid Alien Races 2.0

## Breaking Changes Inventory

### 1.1 → 1.2 (minor)
- Minimal API changes; mostly bugfixes and DLC (Royalty) additions
- `FleshTypeDef` introduced (but mod already uses it)
- Some `ThingDef` additions for Royalty DLC

### 1.2 → 1.3 (moderate)
- `PawnGenerator` changes to pawn generation pipeline
- `ThoughtDef` schema changes
- `RecipeDef` changes
- Some `PawnRenderer` refactoring started

### 1.3 → 1.4 (moderate)
- `SkillDef` now uses custom XML parsing
- `BackstoryDef.baseDesc` → `BackstoryDef.description` — affects 5 XML files
- `CompUseEffect.CanBeUsedBy` signature changed — affects 6 C# files
- `SerializablePawnList` removed (not used in this mod — confirmed)
- `Corpse Defs` now copy race props — may cause false positives if checking `def.race != null`
- `FleshTypeDef.isOrganic` flag added
- `Manhunter` classes renamed to `AggressiveAnimals` — affects 2 C# files + possibly XML

### 1.4 → 1.5 (MAJOR — biggest jump)
- `Thing.Draw` → `Thing.DynamicDrawPhase`; projectiles now use `DrawAt` — affects 6 C# files
- `MapMeshFlags` enum → `MapMeshFlagDef` — affects 6 C# files
- `PawnRenderer` completely overhauled — affects 10 C# files (the most complex change)
- `ApparelProperties` dramatically changed:
  - Removed: `hatRenderedFrontOfFace`, `hatRenderedAboveBody`, `hatRenderedBehindHead`, `shellRenderedBehindHead`, `forceRenderUnderHair`, `coversHeadMiddle`, `shellCoversHead`, `countsAsMaskForBreathing`
  - New: `renderSkipFlags`, `drawData`, `parentTagDef`
  - Affects 5 XML def files + 1 C# file
- `PawnRenderUtility.DrawEquipmentAndApparelExtras` replaces some PawnRenderer logic
- `BackstoryDef.baseDesc` → `description` (if not already done in 1.4)
- `Manhunter` → `AggressiveAnimals` rename completed
- `Verse` → `RimWorld` namespace migrations for some classes
- `Verse` → `LudeonTK` namespace migrations
- `RaceProperties` multiple field changes
- `Pathfinding` changes
- `Dialog_Rename` changed to abstract generic
- `ShelfBase` split into `StorageShelfBase` and `BookcaseBase`
- `IHaulEnroute` new interface for multi-pawn hauling
- `HiddenItemsManager` + `<hiddenWhileUndiscovered>` tag
- `StatDef` new fields
- `ResearchTabDef` new fields
- `MapMeshFlag` enum → `MapMeshFlagDef` Def class

### 1.5 → 1.6 (moderate)
- `DraggableDimensions` → `DrawStyleCategoryDef` — affects 1 C# file + 1 XML file
- Building `ambientSound` → `CompProperties_AmbientSound` ThingComp
- `RaceProperties.thinkTreeMain` → now a `StatDef` (capitalized) — check XML thinkTree references
- `HediffDef.causesNeed` removed → use `causesNeedOverride` on HediffDef root or `NeedForDrug` list in HediffStage
- `ActiveDropPodInfo` → `ActiveTransporterInfo` — affects 10 C# files (DropShip system)
- `targetParams` rename: `mapAllowed` → something else (check exact name)
- `PawnFinder` lists: "TransportPods" → "Transporters"
- `TerrainDef` field renames
- `PlantDef` field renames
- New `ScenarioDef` abstract base — must inherit for scenario defs
- `InteractionDef` rename: some interaction class renamed
- `ActiveDropPodInfo` → `ActiveTransporterInfo`
- `DraggableDimensions` property → `DrawStyleCategory` returning `DrawStyleCategoryDef`
- Burst compiler entries in AssemblyInfo.cs should be removed

**Objective:** Replace removed apparel rendering tags with the new 1.5 system.

**Removed tags (find and remove):**
- `<hatRenderedFrontOfFace>`
- `<hatRenderedAboveBody>`
- `<hatRenderedBehindHead>`
- `<shellRenderedBehindHead>`
- `<forceRenderUnderHair>`
- `<coversHeadMiddle>`
- `<shellCoversHead>`
- `<countsAsMaskForBreathing>`

**New tags to add (case-by-case, based on what the old tags were doing):**
- `<renderSkipFlags>` — controls when rendering is skipped
- `<drawData>` — detailed rendering position data
- `<parentTagDef>` — parent tag for rendering hierarchy

**Important:** This is the hardest XML change. Each apparel item needs its drawData configured based on what the old flags were doing. See the official Ludeon PawnRenderer documentation for the new system. The general mapping is:
- `hatRenderedFrontOfFace=true` → drawData with front-of-face layer
- `hatRenderedAboveBody=true` → drawData with above-body layer
- `shellRenderedBehindHead=true` → drawData with behind-head layer
- `forceRenderUnderHair=true` → renderSkipFlags to skip hair render conflict

**Step 1:** For each file, grep for removed tags and note which items use them.
**Step 2:** Remove all old tags.
**Step 3:** Add appropriate drawData/renderSkipFlags based on the Ludeon documentation and similar vanilla apparel items.
**Step 4:** Commit
```bash
git add Defs/ThingDefs/
git commit -m "refactor: migrate ApparelProperties to 1.5 drawData system"
```

## Risks and Open Questions

1. **Humanoid Alien Races compatibility**: HAR 2.0 was the dependency for 1.1. It may have been updated or replaced for 1.6. Need to verify HAR exists for 1.6 and update the dependency. If HAR is not available for 1.6, this is a blocker — the entire mod depends on it for alien race support.

2. **External mod DLL dependencies**: The mod references several other mod DLLs (AnimatedProjectile, CompActivatableEffect, CompOversizedWeapon, CompSlotLoadable, CompToggleDef, PawnShields, Thumper). These all need 1.6-compatible versions. Some may be bundled in Assemblies/ already, but they may be 1.1 binaries.

3. **PawnRenderer overhaul complexity**: The 1.5 PawnRenderer overhaul is the single most complex change. The mod heavily customizes pawn rendering (cloaking, xenomorph hidden state, shield rendering). Getting these patches right without the game installed for testing will be difficult. May need iterative testing.

4. **No RimWorld 1.6 installation on this machine**: We can compile against the NuGet reference, but we can't actually load-test the mod. The user will need to test in-game.

5. **.NET on Linux**: The project uses .NET Framework 4.7.2 with MSBuild format. Compiling on Linux requires mono or dotnet SDK. Need to verify availability.

6. **HediffDef.causesNeed**: If any hediff defs in this mod use `<causesNeed>`, they need migration. The initial grep didn't find any, but this should be double-checked during the XML audit.

7. **RaceProperties changes**: Multiple fields on RaceProperties changed across versions. Need to audit the race defs (Yautja, Xenomorph, Synth, Neomorph) for any removed/renamed fields.

8. **MigrationBackup removal**: Make sure nothing in the active projects references the MigrationBackup folder before deleting it.
